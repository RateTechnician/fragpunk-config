## 🧩 About

**FragPunk Config** is a comprehensive configuration tool for FragPunk featuring crosshair customization, FOV changer, sensitivity presets, keybind manager, and performance tweaks.

Based on popular config tools like **FragPunk Config Editor** and **FragPunk Settings Manager**.

---

## ✨ Features

### 🎯 Crosshair & Aim
- Custom Crosshair — design and save multiple crosshair profiles
- FOV Changer — adjust field of view beyond game limits
- Sensitivity Presets — import/export pro player sensitivity settings
- Crosshair Color Picker — RGB and hex color support

### ⌨️ Controls & Keybinds
- Keybind Manager — reassign any action to any key or mouse button
- Macro Recorder — create simple key sequences for practice
- Quick Switch Profiles — load different keybind sets on the fly

### ⚡ Performance & Visuals
- FPS Boost Presets — tweak config files for higher frame rates
- Visual Clarity Tweaks — adjust brightness, contrast, and sharpness
- Network Optimization — suggest optimal in-game network settings
